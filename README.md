# PDFツール - 結合・分割・回転

PHPを使用した簡易的なPDFの結合・分割・回転ツールです。

## 機能概要
- **PDF結合**: 複数のPDFファイルをアップロードし、任意の順序に並び替えて1つのPDFファイルに結合します。
- **PDF分割**: 1つのPDFファイルを指定したページ番号（例: `1,3-5,7`）で分割・抽出します。
  - 複数ページの分割指定がある場合は、各ページごとにPDFを出力してZIPファイルにまとめてダウンロード可能です。
  - 単一ページの抽出またはページ指定がない（全ページ抽出）の場合は、抽出したPDFを出力します。
- **PDF回転**: 1つのPDFファイルをアップロードし、各ページのサムネイルプレビューを確認しながらページ単位で90度ずつ回転（右90°/左90°/180°）できます。
  - 全ページの一括回転や、ページ指定（例: `1, 3-5`）による一括回転にも対応。
  - 回転させた結果を新しいPDFファイルとして出力・ダウンロードできます。

## 今回のアップデート
- **ページ単位の90度回転機能の追加**:
  - 「PDF回転」タブを新設。
  - PDF.jsによる各ページのサムネイルリアルタイム描画と回転アニメーションプレビュー。
  - ページごとの個別回転（右90°/左90°/0°リセット）および全ページ/ページ範囲指定の一括回転機能。
  - バックエンド（FPDI）による各ページの正確な回転出力。
- **ファイル数・ページ数合計の表示**:
  - PDFの結合・分割・回転処理が完了した際、完了メッセージ内に「処理したファイル数」と「合計ページ数」を表示。
- **同時アップロード可能ファイル数の拡張と上限バリデーション**:
  - 最大100ファイル、合計最大200MB、1ファイル最大100MBのアップロードに対応。
- **エラーハンドリングおよびログ機能の強化**:
  - アップロードエラーコードの日本語化、容量10MBでの自動ローテーション対応追跡ログ（`logs/app.log`）。
