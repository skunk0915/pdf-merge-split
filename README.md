# PDFツール - 結合・分割・回転

PHPを使用した簡易的なPDFの結合・分割・回転ツールです。

## 機能概要
- **PDF結合・変換（インラインページ回転＆テキストプレビュー対応）**: 複数のPDF、画像（JPEG, PNG, GIF, WebP）、テキストファイル（.txt）をアップロードし、任意の順序に並び替えて1つのPDFファイルに結合・変換します。
  - PDF・画像: 各ファイル右側の「🔄 ページ回転・プレビュー」からページ一覧を展開し、各ページのサムネイルを見ながらページ単位で90度回転（一括回転/個別回転/リセット）を設定可能。
  - テキストファイル（.txt）: 不要な回転機能は排除し、「📄 テキスト表示」から冒頭3行のテキストプレビューを表示。スライドトグルで全文展開・折りたたみ可能。
  - 画像1枚やテキスト1ファイルのみをアップロードして単体PDF変換・回転ツールとしても利用可能。
- **PDF分割・抽出（プレビュー＆ページ回転対応）**: PDF（および画像・テキスト）の全ページサムネイルグリッドを表示し、抽出対象の選択とページ単位の90度回転（一括回転/個別回転/リセット）をビジュアルに指定して分割・抽出します。
  - ページ指定テキスト入力欄（例: `1,3-5,7`）とカードの選択状態が双方向に同期。
  - テキストファイル選択時は回転UIを自動非表示にし、テキストプレビューを表示。
  - 複数ページの分割指定がある場合は、各ページごとにPDFを出力してZIPファイルにまとめてダウンロード可能です。
  - 単一ページの抽出またはページ指定がない（全ページ抽出）の場合は、抽出したPDFを出力します。
- **PDF回転（PDF・画像対応）**: 1つのファイル（PDF・画像）をアップロードし、各ページのサムネイルプレビューを確認しながらページ単位で90度ずつ回転（右90°/左90°/180°）して保存できます。
  - 一括回転や、ページ指定（例: `1, 3-5`）による一括回転にも対応。

## 今回のアップデート
- **分割プレビューのサムネイルクリックによるプレビュー拡大モーダル新設**:
  - サムネイルクリック時の意図しない回転動作を廃止し、クリックで高解像度の拡大プレビューモーダル（ポップアップ）を表示するよう改善。
  - 対象ページの選択/除外はチェックボックス、向きの調整は下部の回転ボタンで行うUIと明確に役割を分離。
  - モーダル内では高解像度レンダリングによるくっきりとした本文確認、前後のページ移動（「◀ 前のページ」「次のページ ▶」および左右矢印キー）、モーダル内からの直接回転（カードの回転状態とリアルタイム同期）、Escキーでのクローズに対応。
  - サムネイルにホバー時の「🔍 拡大」バッジを追加し、拡大可能であることが直感的に伝わるデザインを導入。
- **分割タブのファイルアップロードエリアの統一（結合タブと同一UI化）**:
  - 分割画面でブラウザ標準の素朴なファイル選択inputが表示されていたのを改め、結合画面・回転画面と統一された「ファイルを選択」ボタンおよびドラッグ＆ドロップゾーン（`.drop-zone`）へ刷新。
  - ドラッグ＆ドロップ（D&D）によるファイル指定に対応し、ドロップゾーン枠内のクリックでも直接ファイル選択ダイアログが開くよう操作性を向上。
  - 選択中のファイルには結合画面と同様にファイル形式バッジ（`[PDF]`, `[画像]`, `[テキスト]`）、ファイル名、ファイルサイズ、削除（クリア）「×」ボタンを表示し、直感的に再選択・解除が可能に。
- **新規ファイル選択時の前回ダウンロードリンク・完了メッセージ自動消去＆分割動線の改善**:
  - 分割画面で1ファイルを分割した後に別のファイルをアップロードした際、前回の完了メッセージおよびダウンロードリンクが画面下部に残っていたため、新しいファイルの分割ボタンを押す前に前回のダウンロードリンクを押してしまい古いファイルが再度ダウンロードされてしまう不具合を解消。
  - 新規ファイル選択時（および設定変更時・タブ切り替え時）に、前回の完了メッセージおよびダウンロードボタンを即座に完全消去（クリア）するよう改善。
  - 分割サマリー直下に「✂️ この設定でPDFを分割」クイック実行ボタンを新設し、ページ構成を確認したその場からワンクリックで分割を実行できるようにUI動線を刷新。
  - ボタン文言も出力予定ファイル数に応じて動的変化（「✂️ この設定で分割（○ファイルをZIPで生成）」など）し、迷わず操作できる一本道のUXを実現。
- **分割アイコンの視認性改善（グレーアウト感の解消）**:
  - 分割（切り離し）状態の境界アイコン（`✂`）がグレーアウトして無効化（disabled）されているように見える問題を解消。鮮明なオレンジ色のハサミバッジと切り取り破線へ刷新し、アクティブな分割状態であることが直感的に伝わるデザインへ改善。
- **連結分割（グループ化分割・ZIP一括出力）機能の追加**:
  - サムネイルプレビュー上でページ間の境界アイコン（`✂` / `📎`）をクリックするだけで、連続するページを1つのPDFに連結したり個別ページに切り離したりできる直感的なUIを新設（例: 10ページ中、1-3を1ファイル、4-6を1ファイル、残りは1pずつ個別分割など）。
  - テキスト指定とも双方向に完全同期し、スラッシュ（`/`）やセミコロン（`;`）で区切ったグループ指定（例: `1-3 / 4-6 / 7 / 8 / 9 / 10`）もサポート。
  - ツールバーに「🔗 すべて連結」「✂️ すべて分割（リセット）」ボタンを新設。
  - 同一グループのページにはグループカラーと「ファイル○ (○p)」バッジを自動付与し、サマリー領域に出力予定ファイル数およびグループ内訳プレビューをリアルタイム表示。
  - 生成された各グループPDFは `_p1-3.pdf`, `_p4-6.pdf`, `_p7.pdf` などの明瞭なファイル名で命名され、1つのZIPファイルにまとめて一括ダウンロード可能。
- **分割PDFの一括ダウンロード（ZIP形式）表示の明確化**:
  - 複数ページの分割処理完了時、各ページごとの個別PDFが1つのZIPファイルにまとめられて一括ダウンロード可能である旨をメッセージおよびダウンロードボタン上に明記（「📦 分割PDFを一括ダウンロード（ZIP形式）」）。
- **PDF分割ボタン押下時に処理が実行されない不具合の修正**:
  - 分割フォーム送信時に送信ボタン（`#splitSubmitBtn`）が即時 `disabled` 化されることで、ボタンの name/value（`split`）がブラウザの送信データから除外され、サーバー側で分割処理が実行されず画面が初期表示に戻っていた不具合を解消。
  - フォーム内に `<input type="hidden" name="split" value="1">` を明示配置し、ボタンの disabled 化処理も非同期遅延実行（`setTimeout`）に改善することで確実な送信を担保。
- **処理完了後のアクティブタブ状態維持**:
  - 分割・回転などの処理実行後にページが再読み込みされた際、操作していた対象タブ（「PDF分割・抽出」や「PDF回転」）をアクティブなまま維持して表示するように改善。
- **テキストファイルのプレビュー抜本改善と回転機能の整理**:
  - テキストファイル（.txt）に不要な回転機能（回転ボタン・角度バッジ）を排除。
  - 従来の無意味なファイルアイコン表示を廃止し、実際のテキスト内容を直接確認できるプレビュー領域を新設。
  - デフォルトは冒頭3行を表示し、スライドトグル（「全文を表示 ▼」「閉じる ▲」）でスムーズに全文展開・折りたたみ可能。
  - テキスト選択時のボタンも「📄 テキスト表示」に切り替え、直感的に操作可能に。
- **回転ボタン文言の適正化（「全ページ」→「一括」）**:
  - 結合画面のファイル内ツールバーにある「全ページ ↻ 90°」等の文言が他の結合ファイルにも影響すると誤解されるため、「一括 ↻ 90°」「一括 ↺ 90°」「リセット」（ツールバータイトルも「このファイルのページ回転」）へ適正化。
  - 分割画面および回転画面のツールバー文言も「一括」に統一。
- **結合・分割画面へのページ単位90度回転機能の統合**:
  - 「PDF結合・変換」画面：各ファイルごとにページを展開し、PDFの各ページや画像を直接90度回転した上で結合・変換保存できるように統合。
  - 「PDF分割・抽出」画面：全ページのサムネイルグリッドを展開し、視覚的なページ選択（チェックボックス双方向連動）とページ単位の90度回転を同時に指定可能に。
  - 画面の切り替えやファイルの再アップロードの手間を完全になくし、結合・分割の流れの中でワンストップで向きを修正可能に改善。
- **画像ファイルの回転対応を全面強化**:
  - 「PDF回転」タブおよび「PDF分割」画面でも、画像（JPG, PNG, GIF, WebP）のアップロード・プレビュー・回転・保存に対応。
- **画像・テキストファイルのPDF変換＆混在結合対応**:
  - 対応形式に画像（JPG, PNG, GIF, WebP）およびテキストファイル（TXT）を追加。
  - ファイルリスト上にファイル形式バッジ（`[PDF]`, `[画像]`, `[テキスト]`）を表示。
  - 日本語フォント（IPAゴシック）と tFPDF による高品質な日本語テキストPDF変換。
- **ファイル数・ページ数合計の表示**:
  - PDFの結合・分割・回転処理が完了した際、完了メッセージ内に「処理したファイル数」と「合計ページ数」を表示。
- **同時アップロード可能ファイル数の拡張と上限バリデーション**:
  - 最大100ファイル、合計最大200MB、1ファイル最大100MBのアップロードに対応。
- **エラーハンドリングおよびログ機能の強化**:
  - アップロードエラーコードの日本語化、容量10MBでの自動ローテーション対応追跡ログ（`logs/app.log`）。
